
# پروژه برنامه نویسی پایتون

# درباره پروژه
این پروژه با زبان پایتون و با هدف تمرین مفاهیم اولیه برنامه نویسی نوشته شده است.

# قابلیت های پروژه

# 1. دستورات شرطی (If)
بررسی سن کاربر و تشخیص بزرگسال یا کودک بودن او.

# 2. حلقه For
دریافت طول و عرض و رسم مستطیل با استفاده از ستاره (*).

# 3. حلقه While
نمایش مداوم پیام تا زمانی که کاربر کلمه stop را وارد کند.
