
# ماشین حساب مهندسی با پایتون

## درباره پروژه
این پروژه یک ماشین حساب مهندسی ساده است که با زبان پایتون طراحی شده و قابلیت انجام عملیات ریاضی و محاسبات مهندسی را دارد.

## قابلیت های پروژه

### 1. عملیات ریاضی
- جمع
- تفریق
- ضرب
- تقسیم
- توان
- درصد

### 2. محاسبات مهندسی
- جذر
- سینوس (Sin)
- کسینوس (Cos)
- تانژانت (Tan)
- لگاریتم (Log)
- لگاریتم طبیعی (Ln)
- فاکتوریل

### 3. عملیات تکمیلی
- قدر مطلق
- گرد کردن به پایین (Floor)
- گرد کردن به بالا (Ceiling)
- محاسبه عدد پی (Pi)

## دستورات استفاده شده
- If / Else
- While Loop
- Switch Case (Match / Case)
- Break
- Input / Print

## کتابخانه مورد استفاده
- Math

## نحوه اجرا
1. نصب Python نسخه 3.10 یا بالاتر
2. دانلود فایل پروژه
3. اجرای فایل ScientificCalculator.py
4. انتخاب عملیات موردنظر از منو

## هدف پروژه
تمرین ساختار Match Case و آشنایی با عملیات ریاضی و توابع کتابخانه Math در پایتون.
