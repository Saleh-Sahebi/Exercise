###ماشین حساب مهندسی پایتون

##درباره پروژه

###این پروژه یک ماشین حساب مهندسی با زبان پایتون است که بدون استفاده از هیچ کتابخانه‌ای طراحی شده است.

##قابلیت‌های پروژه

#1. عملیات ریاضی

- جمع
- تفریق
- ضرب
- تقسیم
- توان
- درصد

#2. محاسبات مهندسی

- جذر با روش نیوتن
- سینوس (Sin)
- کسینوس (Cos)
- تانژانت (Tan)
- لگاریتم (Log)
- لگاریتم طبیعی (Ln)
- فاکتوریل

#3. عملیات تکمیلی

- قدر مطلق (Absolute Value)
- گرد کردن به پایین (Floor)
- گرد کردن به بالا (Ceiling)
- عدد پی (Pi)

##دستورات استفاده شده

- If / Else
- While Loop
- For Loop
- Match / Case
- Break
- Functions
- Input / Print

###نحوه اجرا

1. نصب Python نسخه 3.10 یا بالاتر
2. دانلود فایل پروژه
3. اجرای فایل "ScientificCalculator.py"
4. انتخاب عملیات موردنظر از منو

هدف پروژه

تمرین ساختار Match Case، حلقه‌ها، شرط‌ها و توابع در پایتون و آشنایی با پیاده‌سازی الگوریتم‌های ریاضی بدون استفاده از کتابخانه‌های آماده.
